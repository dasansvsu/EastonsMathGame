# Number Nebula

A colorful math-quest game built with Godot 4. Practice randomized addition and
subtraction with whole numbers from 0 to 1,000.

## Run the game

1. Install Godot 4.3 or newer.
2. Open this folder in Godot, or run `godot --path .`.

## Play

Type an answer and press **Enter** or choose **Check answer**. Correct answers
earn 10 points and build a streak; wrong answers play a gentle low-pitch sound
and let you try again without losing points. Complete 10 problems to finish a
mission, then choose **Play again** for another round.

The space backdrop and rocket are drawn in-game, and the correct/wrong sound
effects are synthesized at runtime, so the project needs no imported assets.
